## 💌 Get on the Wall of Love

Post about INFINIVERSE™ anywhere with **#infiverse** or **#Web5Payments**. Biscuit reads them all and adds his
favourites to the [Wall of Love](https://tusharsrivastava.github.io/infiverse/#wall) by hand.

<details>
<summary>Adding a post (for maintainers)</summary>

Add an entry to the top of `items` in [`wall.json`](wall.json) and commit. The live page re-checks the file every
minute, so anyone with the site open gets a "New review" popup when it lands.

```json
{
  "id": "x:someone-1",
  "platform": "x",
  "author": "@someone",
  "url": "https://x.com/someone/status/123",
  "text": "What they said, exactly as they wrote it.",
  "date": "2026-11-24T10:00:00Z",
  "reply": "Optional INFINIVERSE™ reply. ⭐"
}
```

`platform` is one of `reddit`, `hackernews`, `x`, `bluesky`, `mastodon`, `github` or `other`. `id` just has to be unique.

</details>

INFINIVERSE™ is a joke. **[shark-skills](https://github.com/tusharsrivastava/shark-skills) is not.**

**shark** is a free, open-source Claude Code plugin that runs your coding session like an engineering team: one
operator, parallel lanes, audited merges.

- 🧭 **The main session never writes code.** It becomes the operator: it briefs subagents, checks their work and talks to you.
- 📜 **Contract before parallel work**, so three agents don't rename the same function three different ways.
- 🛡️ **Invariant guard** that checks every diff against your business rules, with `file:line` evidence.
- 🐞 **Root cause before fix**: a real step-through debugger finds the cause, writes a failing test, then a separate agent fixes it.
- ✂️ **Clean commits**: refactors and behaviour changes never share a commit, so `git bisect` actually works.

It won't make you $1 trillion a month. It might save you a weekend.
